Hi, I'm
Jonathan Collins

I'm a passionate software engineer with a first class honours degree in Computer Science for Games from the University of Brighton. I've been coding since I was 10, starting with Python on a Raspberry Pi, moving into Minecraft modding at 12, and never really stopping since.

I've built software across a range of technical domains, from lower-level infrastructure like my UDP Networking Library — a C++ library implementing reliable data transmission, acknowledgement handling, and value interpolation over an inherently unreliable protocol — to full-scale interactive applications like Loco-Comotives, a systems-heavy simulation featuring custom procedural generation and real-time state management. I'm also currently a backend contributor on Due Process, a commercially developed, live multiplayer application with demanding real-time networking and performance requirements. I enjoy solving hard technical problems — particularly around networking, systems architecture, and real-time software — and my goal is to build a career writing robust, performant software.
